# 03 — مصادر بيانات المصحف وتراخيصها

> أهم ملف في التوثيق. **أي خطأ في نص القرآن غير مقبول**، لذلك لا نكتب ولا نجمع النص بأنفسنا، بل نعتمد مصادر موثَّقة ومُراجَعة، ونلتزم بشروط ترخيصها.
> ⚠️ يجب مراجعة صفحة الترخيص لكل مصدر **وقت التنفيذ** لأن الشروط قد تتغير.

## 1. نص القرآن الكريم
| المصدر | الوصف | الترخيص (ملخّص) |
|-------|-------|-----------------|
| **مجمع الملك فهد لطباعة المصحف الشريف** (qurancomplex.gov.sa) | نص حفص بالرسم العثماني + خط المصحف (KFGQPC Uthmanic Script HAFS) | مجاني للاستخدام مع **عدم التعديل** وذكر المصدر — مراجعة شروط المجمع |
| **Tanzil.net** | نص موثّق ومُتحقَّق منه، متاح بصيغ متعددة (عثماني/إملائي) | Creative Commons Attribution-NoDerivs: مسموح الاستخدام التجاري وغير التجاري **بشرط** نسخه كما هو بدون تعديل + ذكر Tanzil مع رابط + إبقاء الترويسة |

**التوصية:** نص المجمع (Uthmani Hafs) مع خط المجمع، والتحقق المتبادل (checksum) مع Tanzil.

## 2. عرض صفحات المصحف (شكل مصحف المدينة)
خياران:

| الخيار | كيف يعمل | المميزات | العيوب |
|-------|----------|---------|--------|
| **أ. خطوط الصفحات (QPC fonts)** | لكل صفحة خط خاص من المجمع (604 خط)، النص يُرسم كحروف | جودة لا نهائية عند التكبير، حجم أصغر، تحديد الآية بدقة | تجهيز أعقد |
| **ب. صور الصفحات** | 604 صورة PNG/WebP | الأبسط في التنفيذ | حجم أكبر، تكبير أقل جودة، تحديد الآية يحتاج إحداثيات |

**التوصية:** نبدأ بـ **(أ) خطوط QPC** — وهي الطريقة المستخدمة في تطبيقات كبيرة مثل Quran.com. بيانات تقسيم الأسطر لكل صفحة متاحة من مشروع Quran.com (QUL — Quranic Universal Library). يُراجَع الترخيص لكل ملف.
وفي الحالتين التحميل **حسب الجزء** (كل جزء ≈ 20 صفحة).

## 3. التلاوات الصوتية
| المصدر | الوصف |
|-------|-------|
| **EveryAyah.com** | ملفات آية بآية لعشرات القرّاء — مثالية للتكرار والحفظ |
| **mp3quran.net** (API) | سور كاملة لمئات القرّاء + API للقوائم |
| **Quran.com API (v4)** | تلاوات + توقيتات الآيات (لتظليل الآية أثناء التلاوة) |

**التوصية:** نبدأ بـ 5–8 قرّاء مشهورين، آية بآية (لدعم التكرار وتظليل الآية). يُفضَّل استضافة نسخة على CDN خاص بالأكاديمية بعد التأكد من الإذن، لتجنب الاعتماد الكامل على طرف خارجي.

> 💡 **فكرة مميزة:** تسجيلات بأصوات مشايخ أكاديمية ابن الجزري أنفسهم — ده يميّز التطبيق عن غيره.

## 4. التفسير
| التفسير | ملاحظة |
|--------|--------|
| **التفسير الميسر** (مجمع الملك فهد) | مختصر، مناسب جداً للتطبيق |
| **المختصر في التفسير** (مركز تفسير) | ممتاز، يحتاج مراجعة الإذن |
| السعدي / ابن كثير | متاحة عبر Quran.com API و QUL |

تُحمَّل كملفات اختيارية (لا تُدمج في حجم التطبيق الأساسي).

## 5. الأذكار والأدعية
- **حصن المسلم** (سعيد القحطاني) — متداول ومستخدم بكثرة؛ **يُراجَع إذن الاستخدام**. بديل آمن: كتابة الأذكار من الأحاديث الصحيحة مباشرة بمراجعة مشايخ الأكاديمية مع ذكر التخريج.

## 6. مواقيت الصلاة
- حساب محلي بالكامل بمكتبة `adhan` (طرق حساب: الهيئة المصرية العامة للمساحة، أم القرى، رابطة العالم الإسلامي…) — **لا تحتاج API ولا إنترنت**.

- [ ] مراجعة شيخ مُجاز لعيّنة من صفحات المصحف داخل التطبيق قبل النشر.
