# 08 — خطة التنفيذ والمراحل

> التقديرات لمطوّر **بدون خبرة سابقة في Flutter**، يعمل 4–6 ساعات يومياً، مع Claude Code يكتب أغلب الكود ويشرحه.
> نطاق الإصدار الأول: **المصحف + قسم الفقه (مالكي وشافعي)** — انظر [ملف 01](01-VISION-AND-SCOPE.md).

- [x] إنشاء مشروع Flutter `ibneljezery_app`.

## المرحلة 1أ — الإصدار السريع (حوالي 4 أسابيع)
**Backend (Laravel) — 4–6 أيام:**
- [x] طبقة `Api/V1` (Spatie Route Attributes + اللغة من هيدر `Accept-Language`).
- [x] جداول وModels: `learning_sections` / `learning_subjects` / `lessons` + Enums (`ContentStatusEnum`, `MadhhabEnum`, `LevelEnum`).
- [x] Filament: الأقسام + المواد + الدروس، مع المراجعة (إرسال ← اعتماد/رفض ← نشر) ودور `sharia_reviewer`. تعديل نص درس معتمد يرجّعه مسودة.
- [x] Endpoints `learning/*` (+ اختبارات). باقي `app/config`.
- [x] صفحة سياسة الخصوصية: `/privacy` في Laravel (عربي + إنجليزي). + أيقونة التطبيق (ربع الحزب) واسمه "ابن الجزري".

**التطبيق (Flutter):**
- [x] المصحف كنص: 604 صفحة + فهرس السور والأجزاء + بحث (بيتجاهل التشكيل) + آخر قراءة + **علامات الورد** (01 §2.1.1).
- [x] قسم الفقه: اختيار المذهب (بيتحفظ) ← المواد ← الدروس، كاش أوفلاين، والآيات في الدروس `[[2:255]]` بتتعرض من المصحف المدمج.
- [x] الإعدادات: الثيم (فاتح/داكن/تلقائي) + حجم خط المصحف + إدارة علامات الورد. (الوضع "الورقي" لسه).

**الإطلاق:** Internal testing ← Closed testing (14 يوماً إلزامياً لو حساب شخصي) ← Production.

## المرحلة 1ب — المصحف الكامل (3–4 أسابيع، كتحديث بعد 1أ)
- [x] صفحات مصحف المدينة: 15 سطر بخطوط المجمع QCF V1 (خط لكل صفحة ~30KB، بيتنزل أول مرة ويتحفظ، و"تنزيل المصحف كله" من إعدادات المصحف) + إطار مزخرف والصفحة كاملة من غير scroll + تقليب أفقي/رأسي. ترتيب السطور: `tool/build_mushaf_layout.js`. لو مفيش نت ← الصفحة بتتعرض نص.
- [x] التلاوة: 7 قرّاء (EveryAyah آية بآية)، تشغيل من آية / الصفحة / مقطع الورد، تكرار الآية (1–10)، تلوين الآية الحالية والتقليب معها. + التشغيل في الخلفية مع إشعار وشاشة القفل (`just_audio_background`) + تنزيل التلاوة جزء جزء بدون نت.
- [ ] القرّاء من لوحة التحكم (جدول `reciters`) — حالياً القائمة ثابتة في التطبيق، وكفاية للإصدار الأول.

> **الإجمالي للمرحلتين 1أ + 1ب ≈ 7–9 أسابيع** (= الخطة الكاملة). تقسيمها لمرحلتين يخلّي التطبيق ينزل المتجر أسرع، ومدة الـ 14 يوماً الإلزامية تمشي بالتوازي مع شغل 1ب.
