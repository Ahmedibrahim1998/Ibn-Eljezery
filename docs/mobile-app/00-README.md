# تطبيق ابن الجزري — فهرس التوثيق

> تطبيق موبايل (Android أولاً عبر Google Play، ثم iOS لاحقاً) يقدّم **المصحف الشريف** و**أقسام تعليم شرعي** (فقه، عقيدة، تجويد، أذكار، …)، ويرتبط بأكاديمية ابن الجزري القائمة (الموقع + لوحة التحكم).

## هل المشروع ممكن؟
**نعم، ممكن تماماً.** والمشروع الحالي (Laravel 12 + Filament) مؤهَّل ليكون الـ Backend ولوحة إدارة المحتوى للتطبيق، فلا نبدأ من الصفر في السيرفر.
التطبيق نفسه مشروع منفصل (Flutter) يتكلم مع Laravel عن طريق API.

## الخلاصة في سطور
1. **Backend:** نفس مشروع Laravel الحالي + طبقة `Api/V1` جديدة + Resources جديدة في Filament لإدارة المحتوى الشرعي.
2. **التطبيق:** Flutter (كود واحد لـ Android و iOS، ويدعم العربية والـ RTL بشكل ممتاز).
3. **المصحف يعمل بدون إنترنت:** النص مدمج في التطبيق، وصفحات المصحف المصوّرة والتلاوات **تُحمَّل حسب الجزء** باختيار المستخدم.
4. **المحتوى الشرعي** (فقه وغيره) يُكتب ويُراجَع من لوحة التحكم، ويُخزَّن في التطبيق للقراءة أوفلاين.
5. **أول إصدار (MVP):** المصحف + قسم الفقه (مالكي وشافعي) بهيكل جاهز، والمحتوى يُضاف لاحقاً من لوحة التحكم. الأذكار والمواقيت والقبلة في المرحلة 2 (انظر ملف 08).
