# 02 — المعمارية والتقنيات

## 1. الصورة العامة

```
┌────────────────────────────┐          HTTPS / JSON           ┌───────────────────────────────────┐
│   تطبيق Flutter (Android)  │  ─────────────────────────────▶ │   Laravel 12 (المشروع الحالي)      │
│                            │      /api/v1/...  (Sanctum)     │                                   │
│  • المصحف (أوفلاين)         │                                 │  • Api/V1 Controllers (جديد)       │
│  • الدروس (كاش محلي)        │ ◀───────────────────────────── │  • Services + Repositories        │
│  • الأذكار / المواقيت       │                                 │  • Filament: إدارة المحتوى (جديد)  │
│  • SQLite محلي              │                                 │  • MySQL                          │
└─────────────┬──────────────┘                                 └──────────────┬────────────────────┘
              │ تحميل ملفات الأجزاء والصوت                                       │
              ▼                                                                 ▼
┌────────────────────────────┐                                 ┌───────────────────────────────────┐
│ CDN / Storage (صور + mp3)  │                                 │ Firebase Cloud Messaging (إشعارات) │
└────────────────────────────┘                                 └───────────────────────────────────┘
```

## 2. لماذا Flutter للتطبيق؟
| المعيار | Flutter | React Native | Native (Kotlin) |
|--------|---------|--------------|-----------------|
| كود واحد Android + iOS | ✅ | ✅ | ❌ |
| دعم العربية و RTL | ممتاز | جيد | ممتاز |
| أداء عرض صفحات المصحف والخطوط الكبيرة | ممتاز (رسم مباشر) | متوسط | ممتاز |
| مكتبات جاهزة (مواقيت، قبلة، صوت، SQLite) | متوفرة | متوفرة | متوفرة |
| سرعة التطوير | عالية | عالية | أبطأ |

**التوصية: Flutter.** أغلب تطبيقات المصاحف الحديثة مفتوحة المصدر بقت Flutter أو Native، و Flutter بيدّينا iOS لاحقاً بدون إعادة كتابة.

## 3. التقنيات المقترحة

### التطبيق (Flutter)
| الغرض | الحزمة المقترحة |
|------|-----------------|
| إدارة الحالة | `flutter_riverpod` |
| التنقّل | `go_router` |
| قاعدة بيانات محلية | `drift` (SQLite) — للمصحف والعلامات والدروس المحفوظة |
| إعدادات بسيطة | `shared_preferences` |
| طلبات الشبكة | `dio` |
| تحميل الملفات بالخلفية | `background_downloader` |
| تشغيل الصوت | `just_audio` + `audio_service` (تشغيل في الخلفية وعلى شاشة القفل) |
| مواقيت الصلاة | `adhan` (حساب محلي بدون إنترنت) |
| القبلة | `flutter_qiblah` أو حساب يدوي + `flutter_compass` |
| الإشعارات | `firebase_messaging` + `flutter_local_notifications` |
| التاريخ الهجري | `hijri` |
| الترجمة | `flutter_localizations` + `intl` (عربي أساسي، إنجليزي ثانوي) |
| عرض محتوى الدروس | `flutter_html` أو Markdown |

### الـ Backend (المشروع الحالي)
| الغرض | ملاحظة |
|------|--------|
| Laravel 12 + PHP 8.2 | موجود |
| Sanctum | موجود — لتوكنات التطبيق |
| Spatie Route Attributes | موجود — للـ routes في Controllers الـ API |
| Validated DTO | موجود — للتحقق من الطلبات |
| Filament 3 + Shield | موجود — نضيف Resources المحتوى الشرعي وصلاحية "مراجع شرعي" |
| Spatie Media Library | **جديد مقترح** — لرفع ملفات الصوت والصور للدروس |
| `laravel-notification-channels/fcm` | **جديد** — للإشعارات (مرحلة 2) |

## 4. أين يعيش كل شيء؟

| البيانات | مكانها | السبب |
|---------|--------|-------|
| نص القرآن (6236 آية) + أسماء السور + الأجزاء | **مدمج في التطبيق** (SQLite) | ثابت لا يتغير، حجمه صغير (~3–5 ميجا)، ويجب أن يعمل أوفلاين |
| صور/خطوط صفحات المصحف | **تحميل حسب الجزء** من CDN | الحجم الكلي كبير (~50–150 ميجا) |
| ملفات التلاوة الصوتية | **تحميل/بث حسب الجزء والقارئ** | كل قارئ ~0.5–1.5 جيجا للمصحف كامل |
| التفسير | تحميل اختياري (ملف لكل تفسير) | |
| الدروس الشرعية والأذكار | **من الـ API** ثم كاش محلي | يتم تحديثها من لوحة التحكم بدون تحديث التطبيق |
| العلامات وآخر قراءة | محلي، ومزامنة مع السيرفر لو مسجّل دخول | |

> **ملاحظة:** نص القرآن **لا يُخزَّن في قاعدة بيانات Laravel ولا يُعدَّل من لوحة التحكم إطلاقاً** — يُدمج كملف ثابت من مصدر موثوق (انظر ملف 03) لضمان عدم حدوث أي خطأ في كتاب الله.
