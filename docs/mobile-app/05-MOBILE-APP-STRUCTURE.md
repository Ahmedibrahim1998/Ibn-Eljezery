# 05 — هيكل تطبيق Flutter

## 1. هيكل المجلدات (Feature-first)
```
ibneljezery_app/
├── assets/
│   ├── db/quran.db                 ← نص القرآن + السور + الأجزاء + الأحزاب + تقسيم الصفحات (مدمج)
│   ├── fonts/                      ← خط المجمع للنص + خط الواجهة العربي
│   └── images/
├── lib/
│   ├── main.dart
│   ├── app/                        ← الثيم، الراوتر، اللغات
│   ├── core/
│   │   ├── network/                ← Dio client + interceptors (Accept-Language, token)
│   │   ├── database/               ← drift: جداول المستخدم المحلية
│   │   ├── downloads/              ← مدير تحميل الأجزاء والصوت
│   │   └── widgets/
│   └── features/
│       ├── mushaf/                 ← عرض الصفحات، الفهرس، البحث، العلامات
│       ├── audio/                  ← المشغل، القرّاء، التكرار
│       ├── tafsir/
│       ├── learning/               ← الأقسام، المواد، الدروس
│       ├── azkar/
│       ├── prayer_times/
│       ├── qibla/
│       ├── downloads_manager/      ← شاشة "الأجزاء المحمّلة" وإدارة المساحة
│       ├── auth/
│       └── settings/
├── android/
└── test/
```
كل feature داخله: `data/` (مصادر البيانات) — `domain/` (النماذج) — `presentation/` (الشاشات + providers).

## 2. التحميل حسب الجزء
```
المستخدم يفتح صفحة في جزء غير محمّل
        │
        ▼
 هل خطوط/صور الجزء موجودة محلياً؟ ── نعم ──▶ اعرض الصفحة
        │ لا
        ▼
 اعرض النص العادي فوراً (من quran.db المدمج) + زر "تحميل الجزء X (≈ 3 ميجا)"
        │
        ▼
 تحميل بالخلفية ← تحقق من الـ checksum ← حفظ في مجلد التطبيق ← إعادة عرض الصفحة بشكل المصحف
```
- شاشة **"إدارة التحميلات"**: قائمة الـ 30 جزءاً، حالة كل جزء، الحجم، حذف/تحميل الكل.
- نفس الفكرة للصوت: لكل قارئ × جزء.
- التحميل يكمل لو التطبيق اتقفل (`background_downloader`) ويدعم الاستكمال بعد انقطاع النت.
- خيار "التحميل على Wi-Fi فقط".

## 3. العمل بدون إنترنت
| الميزة | بدون نت؟ |
|-------|----------|
| المصحف نصاً | ✅ دائماً |
| المصحف بشكل الصفحات | ✅ للأجزاء المحمّلة |
| التلاوة | ✅ للمحمّل / ❌ البث |
| الدروس | ✅ ما تم فتحه أو حفظه سابقاً |
| الأذكار | ✅ (نسخة مدمجة + تحديث من السيرفر) |
| المواقيت والقبلة | ✅ (حساب محلي + GPS) |

## 4. التصميم
- **RTL افتراضي** والعربية اللغة الأساسية.
- هوية الأكاديمية (الألوان والشعار من الموقع الحالي).
- أوضاع العرض: فاتح، داكن، "ورقي" (لون كريمي للقراءة).
- حجم خط قابل للتعديل في وضع النص والدروس.
- إمكانية الوصول: دعم TalkBack والتباين العالي.
